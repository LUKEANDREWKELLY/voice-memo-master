How to make a key (2 minutes)
  1. Open github.com/settings/personal-access-tokens/new (signed in as LUKEANDREWKELLY).
  2. Name it anything, like portfolio upload. Pick an expiration (90 days is fine).
  3. Repository access: Only select repositories → voice-memo-master.
  4. Permissions → Repository permissions → Contents → Read and write. Leave everything else alone.
  5. Tap Generate token, copy it (starts with github_pat_), paste it above, tap Save key. It's kept only in this browser. Forget key wipes it. The same key slot is shared with Voice Memo Master.
